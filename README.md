This repository contains my learning journey with Playwright using TypeScript.

The project focuses on applying QA Automation best practices such as Page Object Model (POM), reusable functions, clean test structure, and scalable test design.

## Tech Stack

- Playwright
- TypeScript
- Node.js

## Features Covered

- Login
- Product Sorting
- Product Filtering
- Assertions
- Page Object Model (POM)

## Installation
npm install

## Learning Goals
This repository is created to improve my QA Automation skills while learning Playwright and modern test automation practices.
